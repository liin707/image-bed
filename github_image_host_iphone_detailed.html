GitHub 图床管理助手

从选择图片、预览裁剪，到批量上传与外链管理，一页完成

i

使用前先看这里

这是一份手机优先设计的图床工具说明。建议使用 Safari 打开已部署到 GitHub Pages 的网页。

① 配置图床

填写 GitHub 用户名、公开仓库名称和 Personal Access Token。保存后会记在当前浏览器中。

② 添加图片

点击选择图片，可一次勾选多张；也可以从支持拖拽的设备把图片拖入上传区域。

③ 预览与裁剪

每张图片都可以单独预览。拖动裁剪框调整位置，拖动右下角圆点调整范围，再选择需要的画面比例。

④ 上传并复制链接

确认待上传列表无误后，点击上传全部。上传完成后刷新图库，即可复制图片外链。

iPhone 使用提示

请用 Safari 打开网页地址，不要只用「文件」App 的快速预览。选择图片时可从「照片图库」或「浏览」中导入。裁剪和上传期间请保持页面打开，并尽量使用稳定网络。

① 连接你的 GitHub 图床

这一步只需设置一次。用户名和仓库名决定图片最终存放的位置；Token 用于授权网页向你的仓库上传、读取和删除文件。

Token 从哪里获取？

在 GitHub 账户设置中创建 Personal Access Token，并确保它拥有目标仓库所需的访问权限。复制生成的 Token，粘贴到下面输入框。不要把 Token 发给他人。

设置保存在当前浏览器。建议使用仅拥有目标仓库必要权限的 Token；不要在公共设备上保存。

② 选择需要上传的图片

支持一次添加多张图片。图片会先进入待上传区，你可以逐张检查、裁剪或移除；此时还不会上传到 GitHub。
